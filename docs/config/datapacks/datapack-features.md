# Datapack Guides

Tide 2 dramatically reworks the fishing loot system, and it comes with a versatile system for adding fish, crates, and extra loot tables. 

!!! note
    It's recommended that you understand the basics of how datapacks work before reading this guide. Check out [this minecraft wiki page](https://minecraft.wiki/w/Tutorial:Creating_a_data_pack) for more info.

!!! note
    This wiki is still missing info for how to add crates and extra loot tables. Check back later if you're looking for that, or reach out on the Tide discord server for help.

[//]: # (To get started, either create a datapack yourself or download the example datapack from [this repository]&#40;&#41; by pressing code -> download zip and extracting the files. You can also use it as a guide to create your own.)

[//]: # (If you downloaded the example datapack, you can open the pack.mcmeta and change the description to whatever you want. You should also rename the main folder to something else.)

For additional examples, you can look at Tide's [built-in fishing data files](https://github.com/Lightning-64/Tide-2/tree/main/src/generated-1.21.1/resources/data/tide/fishing) or the [Tide Extra Compatibility](https://modrinth.com/datapack/tide-extra-compatibility) datapack.
